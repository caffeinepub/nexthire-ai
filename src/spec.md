# Specification

## Summary
**Goal:** Display all Lead records from the backend collection in a user-friendly table format.

**Planned changes:**
- Create a new page or section that fetches and displays all records from the Leads collection
- Show full name, email, country, target job role, and submission timestamp in a table format
- Format timestamps in a human-readable way
- Handle loading, error, and empty states appropriately

**User-visible outcome:** Users can view all submitted lead records in a table with all their details including when they were submitted.
